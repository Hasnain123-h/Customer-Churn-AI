AI Customer Churn Prediction

About the Project

I developed this project with the help of ChatGPT for learning, coding assistance, debugging, and understanding different components of the application.

How to Run the Project

1. Clone the Repository

Replace "Hasnain123-h" with your GitHub username.

git clone https://github.comHasnain123-h/Customer-Churn-AI.git
cd Customer-Churn-AI

2. Create a Virtual Environment

python -m venv venv

3. Activate the Environment on Windows

venv\Scripts\activate

4. Install Dependencies

pip install -r requirements.txt

5. Run the Streamlit Application

python -m streamlit run app/streamlit_app.py

Run Tests

Run the following command to test the project:

pytest -v
